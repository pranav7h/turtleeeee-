Turtle Interio - static site (no build step)

Deploy on Vercel:
1. Unzip this file. Open the folder so you see index.html, vercel.json and assets/.
2. Go to vercel.com/new -> drag and drop THIS FOLDER (not the .zip file).
   Or: install Vercel CLI, open a terminal in this folder, run:  vercel --prod
3. Framework Preset: Other. Build Command: empty. Output Directory: empty (or ".").
